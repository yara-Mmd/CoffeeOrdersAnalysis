## 🛠️ Key Skills Used:
* Advanced Excel Formulas: Used functions (like XLOOKUP/VLOOKUP or INDEX/MATCH) to connect and retrieve data across sheets.
* Data Formatting: Cleaned and organized raw data directly in Excel for better readability.
* Data Modeling: Established relationships between Orders, Customers, and Products sheets.
* Interactive Visualization: * Sales trends analysis over 4 years.
  * Created dynamic Slicers for Coffee Types and Months to enable easy data filtering.
  * Summarized data using Pivot Tables & Charts.

## 💡 Insights:
* Tracked sales growth and identified peak performance periods.
* Analyzed customer preferences by coffee bean type.
